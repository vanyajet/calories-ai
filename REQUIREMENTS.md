# Calories AI — требования (v1)

Мобильное приложение для подсчёта калорий и КБЖУ с помощью ИИ.
Стек: React Native + Expo (Android первым, установка APK по QR; iOS — позже).

## 1. Главная идея
Приложение — это **календарь питания**. Каждый день — список того, что съедено.
Можно переключаться между днями, добавлять еду в любой день (в т.ч. задним числом).

## 2. Профиль (первый запуск)
- Пол, возраст, вес (кг), рост (см).
- Размер ладони (длина × ширина, см) — **необязательно**, используется ИИ как масштаб, если рука на фото.
- Цель: **держать вес** (по умолчанию), похудеть, набрать.
  - Похудеть = норма − N ккал, набрать = норма + N ккал (N задаётся, по умолчанию 400).
- Уровень активности **не вводится** — активность вносится вручную по дням (см. п. 5).

### Формула нормы
- **Базовый расход (BMR)** — формула Миффлина — Сан Жеора, без коэффициента активности:
  - мужчины: `10·вес + 6.25·рост − 5·возраст + 5`
  - женщины: `10·вес + 6.25·рост − 5·возраст − 161`
- Это «пассивный» расход (как «Энергия покоя» в Apple Watch / Здоровье).
- **Норма дня** = BMR + активные ккал за день (если внесены) + поправка цели.

## 3. Экран дня (главный)
- Сверху — календарь / лента дней, переключение между днями.
- Кольцо: **съедено / осталось** от нормы дня.
- Полоски Б / Ж / У (граммы).
- Карточка «Активность» — сколько активных ккал сожжено (ввод числом).
- Список съеденного: фото (если есть), название, граммы, ккал, Б/Ж/У, время (необязательно).
- Кнопка «+» — добавить еду.

## 4. Добавление еды — способы ввода
1. **Фото** (камера или галерея) → ИИ распознаёт.
2. **Текст** («две котлеты с пюре, 300 г») → ИИ распознаёт.
   - **Голос**: кнопка микрофона использует встроенное распознавание речи телефона и вставляет текст в поле. Никаких внешних API для транскрибации.
3. **Вручную** (с этикетки):
   - ккал (и Б/Ж/У) **на 100 г** + вес съеденного → приложение само считает итог;
   - или сразу **итоговые** ккал (и Б/Ж/У) без веса.

После распознавания ИИ открывается **экран проверки**: можно поменять название, граммы, ккал, Б/Ж/У, удалить или добавить позицию. Ничего не сохраняется без подтверждения.
Время приёма — необязательное поле. Приёмы пищи (завтрак/обед/…) **не выделяем** — просто список.

## 5. Активность
- В каждый день можно ввести одно число — **активные калории** (из Apple Watch, шагомера и т.п.).
- Добавляется к норме этого дня.

## 6. Вес
- Можно внести свой вес на любой день (необязательно).
- В статистике — график веса, если есть записи.

## 7. Статистика
- Период: неделя / месяц.
- По дням: съедено vs норма, **дефицит / профицит**.
- Итого за период: суммарный дефицит/профицит, примерный эквивалент в кг жира (7700 ккал ≈ 1 кг).
- Средние за день: ккал, Б, Ж, У.
- График веса (если есть записи).

## 8. ИИ — правила распознавания
- Модель: **Gemini Flash** последней версии (сейчас `gemini-3.8-flash`, задаётся в env сервера).
- Модель **обязана** вернуть строгий JSON (структурированный вывод). Отказ / «не могу определить» невозможен по схеме.
- По каждой позиции модель даёт **диапазон**: вес (мин–макс, г) и ккал на 100 г (мин–макс), плюс Б/Ж/У на 100 г.
- **Сервер берёт середину диапазона** — это и есть итоговая оценка (детерминированно, в коде, не «на усмотрение» модели).
- Флаг `macros_estimated` — если Б/Ж/У угаданы (соус сверху, начинка не видна и т.п.). В интерфейсе показывается значок «≈».
- Уверенность (`confidence`: high / medium / low) — показывается в интерфейсе.
- Если на фото есть рука и задан размер ладони — используется как масштаб.
- Если на фото не еда — понятная ошибка «еда не найдена».

## 9. Данные и инфраструктура
- Все данные — **только на телефоне** (SQLite). Без аккаунтов и синхронизации.
- Фото копируются в постоянную папку приложения.
- ИИ вызывается через **маленький сервер-прокси** (`server/`), который хранит ключ Gemini. Приложение знает только адрес прокси и общий секрет.

## 10. Настройки
- Язык: русский / английский.
- Тема: светлая / тёмная / системная.
- Редактирование профиля и цели.

## 11. Бэклог (не в v1)
- Избранное / частые блюда в один тап.
- Сканер штрихкодов.
- ИИ задаёт уточняющие вопросы при сильных сомнениях.
- Импорт активности и веса из Apple Health / Google Fit.
- iOS-сборка.
- Аккаунты, синхронизация, общий доступ (жена/муж).
